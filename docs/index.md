# Documentación de Ejercicios Jekyll

## 📋 Propósito
Este documento describe los ejercicios que voy a documentar sobre Jekyll, enfocándome en tres temas principales que cubren desde temas básicos hasta implementaciones más avanzadas.

## 🎯 Temas a Documentar

### 1. Minima 🏗️
**Tema por defecto de Jekyll**
- Configuración básica y personalización
- Estructura de archivos y directorios
- Modificación de estilos CSS y layouts
- Front Matter básico
- Optimización del tema por defecto

### 2. Lagrange 📊
**Tema para documentación técnica y académica**
- Diseño elegante y minimalista enfocado en contenido
- Optimizado para documentación técnica y blogs académicos
- Navegación lateral con jerarquía clara
- Soporte para matemáticas con MathJax
- Syntax highlighting avanzado
### 3. Satellite 🛰️
**Tema para blogs**
- Diseño moderno y profesional para portfolios
- Soporte para proyectos y case studies
- log integrado con categorías y tags
- Dark/Light mode toggle
- Animaciones CSS smooth
