EJERCICIO 2 — Descripción paso a paso para desplegar el tema Jekyll "Lagrange" en GitHub Pages

Fecha: 19 de noviembre de 2025

Introducción

En este documento se describen, en detalle y en formato paso a paso, los procesos para:

  • Importar, configurar y probar el tema Jekyll Lagrange en GitHub Pages.
  • Personalizar la página principal, páginas estáticas y posts.
  • Desplegar el sitio en GitHub Pages usando la rama gh-pages.

1) Forking del repositorio original de Lagrange

La manera recomendada para importar un tema es mediante fork. Esto mantiene el tema sincronizado con el repositorio original y permite actualizaciones futuras.

Pasos:

  1. Accede al repositorio oficial de Lagrange:
  2. Visita: https://github.com/LeNPaul/Lagrange

  3. Este es uno de los repositorios más populares del tema Lagrange.

  4. Hacer Fork del repositorio:

  5. Haz clic en el botón "Fork" en la esquina superior derecha.
  6. Selecciona tu cuenta de GitHub como destino.

  7. GitHub creará una copia del repositorio en tu cuenta.

  8. Clonar el repositorio forkeado en tu máquina local:

git clone https://github.com/tu_cuenta_github/Lagrange.git
cd Lagrange

2) Entender la estructura de Lagrange

Antes de personalizar, es importante conocer la estructura del tema:

Lagrange/
├── _includes/        # Componentes HTML reutilizables
├── _layouts/         # Plantillas de página
├── _posts/          # Tus artículos/posts del blog
├── _sass/           # Estilos SCSS
├── assets/          # Imágenes, CSS compilado, etc.
├── _config.yml      # Configuración principal
├── Gemfile          # Dependencias de Ruby/Bundler
├── index.html       # Página principal
├── about.html       # Página "Acerca de"
└── README.md        # Documentación del tema

3) Configurar _config.yml

El archivo _config.yml es donde personalizas tu sitio. Aquí está la configuración básica para Lagrange:

# Build settings
markdown:            kramdown
highlighter:         rouge
permalink:           /:title
plugins:             [jekyll-paginate, jekyll-sitemap, jekyll-feed, jekyll-seo-tag]

# Customise atom feed settings (this is where Jekyll-Feed gets configuration information)
title:                 'LagrangeAsier'
description:           'Primer tema lagrange Jekyll personalizado por Asier Rodriguez Ormaechea'
author:              'Asier Rodriguez Ormaechea'
url:                 'https://AsierRodriguezO.github.io/lagrange' # the base hostname & protocol for your site
baseurl:             '/lagrange' 
language:            'ES-ES'
copyright:           '2025, Asier'
# Configuración del tema
theme: lagrange

# Configuración del blog
paginate: 5
paginate_path: "/blog/page:num"

# Redes sociales (algunos temas usan esto)
github_username: "AsierRodriguezO"

# Construcción
markdown: kramdown
permalink: /blog/:year/:month/:day/:title/

4) Instalar dependencias y probar localmente

  1. Instalar Bundler y dependencias:
gem install bundler
bundle install
  1. Servir el sitio en local:
bundle exec jekyll serve
  1. Acceder al sitio:
  2. Abre tu navegador en http://localhost:4000/lagrange/
  3. Comprueba que el sitio se visualiza correctamente.

8) Agregar imágenes a posts y páginas

en este caso voy a usar solo url de internet pero si quiero usar imagenes locales las pongo en assets/img/ igual que en el tema Minima.

9) Probar localmente los cambios

Después de hacer cambios, siempre prueba localmente:

bundle exec jekyll serve

10) Git: inicializar, comitear y subir a GitHub

  1. Añadir todos los cambios:
git add .
git commit -m "Personalizar tema Lagrange: configuración y contenido inicial"
  1. Subir a la rama gh-pages:
git push origin gh-pages

Nota: Si el repositorio está en la rama master o main, puedes cambiar: bash git push origin master:gh-pages

11) Configurar GitHub Pages

  1. En GitHub, ve a tu repositorio lagrange

  2. Accede a Settings → Pages

  3. Configura:

  4. Source (Fuente): Selecciona rama gh-pages
  5. Folder (Carpeta): Selecciona / (root)

12) Comprobar el despliegue

  1. Accede a la URL: https://tu_cuenta_github.github.io/lagrange/

  2. Verifica:

  3. ✅ La página principal carga correctamente
  4. ✅ Los posts aparecen en la lista
  5. ✅ Las imágenes se visualizan
  6. ✅ Los links internos funcionan

  7. ✅ La página "Acerca de" se visualiza

  8. Si hay problemas:

  9. Verifica en GitHub: Settings → Pages → Build and deployment para ver logs de error.
  10. Comprueba que baseurl: "/lagrange" está en _config.yml.
  11. Asegúrate de que todas las rutas de imágenes usan {{ site.baseurl }}.

13) Personalización avanzada (opcional)

Cambiar colores y estilos

Edita _sass/ para cambiar los estilos del tema:

// _sass/_variables.scss
$primary-color: #333;
$secondary-color: #666;
$accent-color: #007bff;

Agregar categorías y etiquetas

En _config.yml, agrupa posts por categorías:

---
layout: post
title: "Mi artículo"
categories: [viajes, aventura]
tags: [naturaleza, exploración]
---

Crear páginas adicionales

Crea nuevos archivos .markdown en la raíz:

touch contacto.markdown

---
layout: page
title: Contacto
permalink: /contacto/
---

Formulario o información de contacto aquí...

Resumen de pasos clave

Paso Acción
1 Fork del repositorio Lagrange en GitHub
2 Clonar en local con git clone
3 Configurar _config.yml con tu información
4 Instalar dependencias con bundle install
5 Probar localmente con bundle exec jekyll serve
6 Personalizar index.html, about.html y páginas
7 Crear posts en _posts/
8 Agregar imágenes en assets/img/
9 Hacer commit y push a gh-pages
10 Configurar GitHub Pages en Settings
11 Acceder a la URL pública en unos minutos

Conclusión

El tema Lagrange es una excelente alternativa a Minima para crear blogs profesionales y atractivos. Siguiendo estos pasos, podrás tener un blog completamente funcional y personalizado en GitHub Pages en menos de 30 minutos.

Recuerda que la parte más importante es el contenido de calidad que publiques. ¡Que disfrutes creando tu blog!
